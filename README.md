# 🍣 O Mundo do Sushi

Uma viagem pelos sabores, técnicas e histórias da culinária japonesa.

## 📖 Sobre o projeto

**O Mundo do Sushi** é um site desenvolvido para apresentar diferentes tipos de sushi, suas origens históricas, ingredientes e modos de preparo. O projeto busca compartilhar conhecimentos sobre a culinária japonesa por meio de uma interface organizada, acessível e agradável para os usuários.

A página reúne informações sobre pratos tradicionais e disponibiliza receitas para quem deseja conhecer ou experimentar a preparação dessas iguarias em casa.

## 🎯 Objetivos

- Apresentar diferentes tipos de sushi e suas características.
- Compartilhar informações históricas sobre a culinária japonesa.
- Disponibilizar ingredientes e instruções de preparo.
- Oferecer uma navegação simples entre as seções do site.
- Permitir que os visitantes enviem sugestões e comentários por meio de um formulário.

## 🍱 Tipos de sushi apresentados

O site apresenta as seguintes variedades:

- **Nigiri:** arroz moldado à mão com peixe ou outro ingrediente por cima.
- **Maki:** sushi enrolado em alga nori, arroz e recheio.
- **Uramaki:** versão em que o arroz fica na parte externa do rolo.
- **Temaki:** sushi em formato de cone, preparado com alga e recheios.
- **Sashimi:** fatias de peixe ou outros frutos do mar, sem arroz.
- **Gunkan:** arroz envolvido por alga, formando uma base para os recheios.
- **Oshi Sushi:** sushi prensado, tradicionalmente preparado em uma caixa própria.
- **Chirashi:** arroz coberto com ingredientes variados distribuídos por cima.
- **Futomaki:** rolo maior de sushi, geralmente com vários ingredientes.

## ✨ Funcionalidades

- Navegação por links para acessar diretamente cada seção.
- Apresentação de imagens ilustrativas dos pratos.
- Conteúdo informativo sobre a história de cada variedade.
- Listas de ingredientes e instruções de preparo.
- Formulário de contato para envio de feedback.
- Link para retornar ao início da página.
- Recursos básicos de acessibilidade, como texto alternativo nas imagens e opção para pular diretamente ao conteúdo principal.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação do conteúdo e dos elementos da página.
- **CSS3:** estilização e organização visual da interface.
- **JavaScript:** suporte a funcionalidades interativas.
- **WebP:** formato utilizado em imagens para a apresentação dos pratos.

## 🚀 Como executar o projeto

1. Baixe ou clone o repositório para o seu computador.
2. Abra a pasta do projeto.
3. Verifique se os arquivos CSS, JavaScript e as imagens estão nos diretórios correspondentes.
4. Abra o arquivo `index.html` em um navegador, como Google Chrome, Microsoft Edge ou Firefox.

Também é possível utilizar a extensão **Live Server** no Visual Studio Code para executar a página em um servidor de desenvolvimento local.

## 📱 Compatibilidade

O site utiliza a configuração de viewport para permitir a adaptação da página a diferentes tamanhos de tela. A responsividade visual depende das regras implementadas no arquivo `css/style.css`.

## 📝 Considerações finais

O projeto **O Mundo do Sushi** combina conteúdo informativo e receitas culinárias em uma página web dedicada à gastronomia japonesa. Além de apresentar diferentes variedades de sushi, oferece aos visitantes uma maneira prática de conhecer seus ingredientes, histórias e técnicas de preparo.
